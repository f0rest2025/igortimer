# igortimer

Десктопное приложение для учета рабочего времени с плавающим окном, поддержкой SQLite и отчетами.

## Возможности
- **Плавающее окно**: Маленькое полупрозрачное окно поверх всех окон.
- **Учет по сегментам**: Время сохраняется как отдельные участки (работа, пауза, простой).
- **SQLite**: Все данные хранятся локально в файле `data/tracker.db`.
- **Детектор простоя**: Отслеживание неактивности (мышь/клавиатура).
- **Экспорт в Excel**: Готовые отчеты для клиентов.

## Установка

1. Убедитесь, что у вас установлен **Python 3.11+**.
2. Склонируйте репозиторий или скачайте файлы.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск
```bash
python main.py
```

## Использование
- **Перетаскивание**: Зажмите левую кнопку мыши на окне, чтобы переместить его.
- **Старт/Пауза (▶/Ⅱ)**: Начинает или временно останавливает учет времени.
- **Заметка (✎)**: Позволяет добавить комментарий к текущему интервалу работы.
- **Клиенты**: При первом запуске создаются демонстрационные клиенты. Сменить клиента можно через меню (⋮).

## Файлы
- `main.py`: Точка входа в приложение.
- `db.py`: Модуль работы с базой данных SQLite.
- `floating_timer.py`: Реализация UI плавающего окна.
- `idle_detector.py`: Фоновый поток для отслеживания активности.
- `export_excel.py`: Логика выгрузки данных.
- `data/`: Папка, где создается файл базы данных.

## Юридическая информация
Лицензия Apache-2.0. Не содержит функций записи звука или экрана.
