# IgorTimer

> Десктопное приложение для **учёта рабочего времени** и **записи экрана** во время работы с клиентами.  
> Плавающее окно поверх всех приложений, запись всех мониторов одновременно, поиск записей через браузер.

## ✨ Возможности

### ⏱ Учёт времени
- **Плавающее окно** — маленькое полупрозрачное окно поверх всех программ, перетаскивается мышью
- **Учёт по сегментам** — время сохраняется как отдельные участки (работа, пауза, простой)
- **Детектор простоя** — автоматически определяет неактивность мыши/клавиатуры
- **Напоминания** — всплывающие уведомления по расписанию прямо в окне таймера
- **Экспорт в Excel** — готовые отчёты по клиентам
- **SQLite** — все данные хранятся локально в `data/tracker.db`

### 🎬 Запись экрана
- **Захватывает все мониторы** — автоопределение, работает с одним или двумя дисплеями без настройки
- **Системный звук через pyaudiowpatch** — WASAPI loopback записывает весь звук Windows (браузер, звонки, видео) без каких-либо дополнительных драйверов и настроек
- **Синхронизация с таймером** — запись стартует/ставится на паузу/останавливается вместе с таймером автоматически
- **Пауза / Возобновление** — запись разбивается на сегменты, при остановке склеивается в один MP4
- **Сжатие H.264** — кодек libx264, CRF 28, 15 FPS: читаемый текст при минимальном размере файла
- **Мигающий индикатор ⏺** — показывается прямо в окне таймера пока запись идёт
- **Выбор папки хранения** — можно указать любой диск/папку в Настройках
- **Хранение** — `recordings/YYYY-MM-DD/ЧЧ-ММ_ИмяКлиента.mp4` (по умолчанию)

### 🔍 Веб-интерфейс поиска записей
- Поиск по имени клиента и диапазону дат
- Ссылки на записи прямо из журнала работы с клиентом
- Встроенный HTML5-видеоплеер — смотрите прямо в браузере
- Статистика по времени и объёму записей
- Открывается из меню **⋮ → Поиск записей** или горячей клавишей

## 🚀 Установка и запуск

### Способ 1 — Готовый установщик (рекомендуется)

Скачайте `igortimer-setup-0.3.0.exe` со страницы [**Releases**](https://github.com/f0rest2025/igortimer/releases).  
Устанавливается без Python — всё включено.

### Способ 2 — Из исходного кода

**Требования:** Python 3.11+, [FFmpeg](https://ffmpeg.org/download.html) в PATH

```bash
git clone https://github.com/f0rest2025/igortimer.git
cd igortimer
pip install -r requirements.txt
python main.py
```

#### Запуск веб-поиска записей отдельно
```bash
streamlit run app.py
# Откроется http://localhost:8501
```

## 🎤 Запись звука

Звук записывается через **pyaudiowpatch** (WASAPI loopback) — надёжный метод, работающий на всех современных Windows без каких-либо настроек:

- Захватывает **весь системный звук**: браузер, Zoom, Teams, видео, музыку — всё что слышно в колонках/наушниках
- Работает даже если микрофон выключен или отсутствует
- Не требует включения «Stereo Mix» в настройках Windows
- Если `pyaudiowpatch` недоступен — запись продолжается без звука (только видео)

> **Установка зависимости** (входит в `requirements.txt`):
> ```bash
> pip install pyaudiowpatch
> ```

## 📁 Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа, инициализация всех модулей |
| `floating_timer.py` | UI плавающего окна таймера |
| `recorder.py` | Движок записи (FFmpeg видео + pyaudiowpatch аудио) |
| `recorder_dialog.py` | Диалог ввода имени клиента перед записью |
| `app.py` | Streamlit веб-интерфейс поиска записей |
| `journal_window.py` | Окно журнала работы с клиентом |
| `settings_window.py` | Окно настроек (горячие клавиши, папка записей, цвет) |
| `db.py` | SQLite: таймер + записи |
| `hotkey_definitions.py` | Все горячие клавиши и их дефолты |
| `idle_detector.py` | Фоновый поток отслеживания активности |
| `export_excel.py` | Экспорт отчётов |
| `data/tracker.db` | База данных (создаётся автоматически) |
| `recordings/` | Папка с видеозаписями (по умолчанию) |

## 🏗 CI / CD

После каждого push в `main` GitHub Actions автоматически:
