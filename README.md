# IgorTimer

> Десктопное приложение для **учёта рабочего времени** и **записи экрана** во время работы с клиентами.  
> Плавающее окно поверх всех приложений, запись двух мониторов одновременно, поиск записей через браузер.

## ✨ Возможности

### ⏱ Учёт времени
- **Плавающее окно** — маленькое полупрозрачное окно поверх всех программ, перетаскивается мышью
- **Учёт по сегментам** — время сохраняется как отдельные участки (работа, пауза, простой)
- **Детектор простоя** — автоматически определяет неактивность мыши/клавиатуры
- **Напоминания** — всплывающие уведомления по расписанию прямо в окне таймера
- **Экспорт в Excel** — готовые отчёты по клиентам
- **SQLite** — все данные хранятся локально в `data/tracker.db`

### 🎬 Запись экрана (новое в v0.2.0)
- **Автоматически захватывает все мониторы** — работает с одним или двумя дисплеями без настройки
- **Системный звук** — записывает весь звук Windows через WASAPI loopback (без дополнительных драйверов)
- **Микрофон** — подмешивается автоматически если доступен; если выключен — запись продолжается
- **Пауза / Возобновление** — запись разбивается на сегменты, склеивается в один MP4 при остановке
- **Сжатие H.264** — кодек libx264, CRF 28, 15 FPS: читаемый текст при минимальном размере файла
- **Хранение** — `recordings/YYYY-MM-DD/ЧЧ-ММ_ИмяКлиента.mp4`

### 🔍 Веб-интерфейс поиска
- Поиск записей по имени клиента
- Фильтр по диапазону дат
- Встроенный HTML5-видеоплеер — смотрите прямо в браузере
- Статистика по времени и объёму записей

## 🚀 Установка и запуск

### Способ 1 — Готовый установщик (рекомендуется)

Скачайте `igortimer-setup-0.2.0.exe` со страницы [**Releases**](https://github.com/f0rest2025/igortimer/releases).  
Устанавливается без Python — всё включено.

### Способ 2 — Из исходного кода

**Требования:** Python 3.11+, [FFmpeg](https://ffmpeg.org/download.html) в PATH

```bash
git clone https://github.com/f0rest2025/igortimer.git
cd igortimer
pip install -r requirements.txt
python main.py
```

#### Запуск веб-поиска записей
```bash
streamlit run app.py
# Откроется http://localhost:8501
```

## 🎤 Настройка звука (для записи)

Приложение автоматически пробует захватить системный звук в следующем порядке:

1. **WASAPI loopback** — работает из коробки на большинстве систем
2. **Stereo Mix (DirectShow)** — если WASAPI недоступен

Если звук не захватывается — включите **Stereo Mix**:
> Правая кнопка на иконке звука → *Устройства записи* → правая кнопка в пустом месте → *Показать отключённые* → включить **Stereo Mix**

## 📁 Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа, инициализация всех модулей |
| `floating_timer.py` | UI плавающего окна таймера |
| `recorder.py` | Движок записи экрана (FFmpeg, мульти-сегменты) |
| `recorder_dialog.py` | Диалог ввода имени клиента перед записью |
| `app.py` | Streamlit веб-интерфейс поиска записей |
| `db.py` | SQLite: таймер + записи |
| `hotkey_definitions.py` | Все горячие клавиши и их дефолты |
| `idle_detector.py` | Фоновый поток отслеживания активности |
| `export_excel.py` | Экспорт отчётов |
| `data/tracker.db` | База данных (создаётся автоматически) |
| `recordings/` | Папка с видеозаписями |

## 🏗 CI / CD

После каждого push в `main` GitHub Actions автоматически:
1. Собирает `igortimer.exe` через PyInstaller
2. Упаковывает в `igortimer-setup-<version>.exe` через Inno Setup
3. Создаёт GitHub Release с прикреплённым установщиком
